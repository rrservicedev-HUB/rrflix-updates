# RRFlix — aggiornamenti

Questo repository contiene **solo** i pacchetti dell'interfaccia compilata di RRFlix
(`rrflix-web-X.Y.Z.zip`), pubblicati come Release.

Le app RRFlix (Android, Android TV, Windows) li scaricano da qui per aggiornarsi
senza essere reinstallate. Il codice sorgente non è in questo repository.
